# KDR Channels
This is a Simple bot that automatically attaches a role based on the user's KD within Battlefield REDSEC
Use "/admin kdroles add/list/remove" to manage the attached roles and set their minimum KD to get that specific role.
If you hit the minimum for the next KD role, it will remove the old and set it to the higher role. 
It checks all users that register with "/register \'ea-username\'" every 12 hours to update their roles.
You can also generate a button where users can register with, with "/admin generate register".
